# Articulare: styled mockup

An interactive mockup of **Articulare** (Read · Chat · Write), a learning tool designed for the final synthesis of EPOL 479, *Machine Learning and Human Learning* (University of Illinois Urbana-Champaign, Fall 2026).

**Open it:** https://karinaykh.github.io/articulare-mockup/

This is a work-in-progress design mockup with sample content. No AI runs behind it. Hegel's text is J. B. Baillie's 1910 translation of the *Phenomenology of Mind*, which is in the public domain. The passage shown (§§83–87) follows the 1910 first edition (London: Swan Sonnenschein), checked against the scan at https://archive.org/details/cu31924097557171.
